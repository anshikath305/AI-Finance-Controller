# UI/UX Design System — AI Finance-Ops Controller

## 1. Visual Identity
- **Tone**: Professional, Analytical, Trustworthy.
- **Palette**:
  - Primary: `#1a1a1a` (Deep Charcoal)
  - Accent: `#0066cc` (Finance Blue)
  - Success: `#22c55e` (Emerald)
  - Warning: `#f59e0b` (Amber)
  - Error: `#ef4444` (Rose)
  - Secondary: `#94a3b8` (Slate Gray)

## 2. Typography
- **Primary**: Inter / System Sans.
- **Styles**:
  - Headings: Bold/Black, low tracking (-0.02em).
  - Metrics: Black, tabular-nums.
  - Data labels: 10px uppercase, high tracking (0.2em).

## 3. Core Components

### A. Metric Cards
High-density summary values with sub-labels and trend indicators.

### B. Comparison Workspace
Side-by-side Bank vs Ledger view with checkmarks/warnings for specific field alignment.

### C. Analytical Badges
Consistent status tags (MATCHED, POSSIBLE_MATCH, EXCEPTION) with semantic colors.

### D. Grounded Copilot
A bottom-right floating interface with structured data rendering (mini-tables and summary cards).

## 4. Interaction Patterns
- **Upload**: Two-step guided file selection with immediate validation feedback.
- **Review**: Carousel-style navigation through ambiguous cases.
- **Export**: Transparent report download indicating audit-readiness.
